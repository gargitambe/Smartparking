ABOUT SMARTPARK

Parking management made simple

SmartPark is a web-based full-stack Java project that connects a user-friendly frontend with a Spring Boot backend and MySQL database.

🎯

Our Purpose

The system helps users discover parking locations, select a slot, enter booking details, complete a testing payment and maintain a booking history.

💻

Technology

Frontend: HTML, CSS, JavaScript and Bootstrap-style responsive design. Backend: Java 17, Spring Boot and REST APIs. Database: MySQL with Spring Data JPA.

Project modules

Separate user and admin workflows.

👤 User Module

Registration, login, dashboard, locations, slot selection, booking, demo payment, confirmation, booking history and profile.

👨‍💼 Admin Module

Admin dashboard, location management, slot management, user list, booking list and reports.

📍 Location Module

Parking location details include address, city, total slots, description and a Google Maps URL.

💳 Demo Payment

UPI, QR, card and pay-at-parking options are shown for testing only. No real money is processed.

SmartPark • Software-based parking management • No IoT hardware
